# Загрузка PDF в проект

`pdf_uploader.py` принимает путь к PDF и сохраняет копию в папку `documents`
рядом с программой. Папка создаётся автоматически при первой загрузке.
Нужен Python 3.10 или новее; дополнительные библиотеки не требуются.

## Запуск

В терминале, открытом в папке проекта:

```bash
python3 pdf_uploader.py "/полный/путь/к/документу.pdf"
```

Пути с пробелами нужно заключать в кавычки. Поддерживаются относительные пути
и пути с `~`, например `"~/Downloads/Лекция 1.pdf"`.

Можно запустить программу без аргументов и ввести путь по запросу:

```bash
python3 pdf_uploader.py
```

При вводе по запросу вводите сам путь без окружающих кавычек.

Другую папку хранения можно указать явно:

```bash
python3 pdf_uploader.py "./lecture.pdf" --storage-dir "./my_documents"
```

После загрузки программа печатает полный путь к сохранённому документу.
Этот путь можно передать модулю распознавания или обработки PDF.

## Подключение к другим частям проекта

```python
from pdf_uploader import upload_pdf

saved_path = upload_pdf("/полный/путь/к/документу.pdf")
print(saved_path)
```

`upload_pdf()` возвращает объект `pathlib.Path`. При неправильном пути,
неподходящем файле или ошибке чтения/записи функция выбрасывает `ValueError`
или `OSError` (включая `FileNotFoundError`), которые может обработать вызывающий код.

## Поведение загрузчика

- Исходный файл остаётся на месте; в хранилище создаётся копия.
- При совпадении имён используются `lecture_1.pdf`, `lecture_2.pdf` и так далее.
- Проверяются существование файла, расширение `.pdf` без учёта регистра
  и заголовок `%PDF-`. Это базовая проверка, а не полная проверка структуры PDF.
- PDF без текстового слоя тоже принимаются. Распознавание и составление
  вопросов выполняются другими частями системы.
- Файлы копируются порциями; при ошибке копирования незавершённая копия удаляется.
- При успешной загрузке код завершения — `0`, при ошибке — `1`, при отмене ввода — `130`.
- Загруженные документы исключены из Git через `.gitignore`.
